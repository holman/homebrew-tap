# holman/homebrew-tap

My personal Homebrew tap. Install anything in here with:

```
brew install holman/tap/<formula>
```

Formulas are auto-generated by [GoReleaser](https://goreleaser.com) when the
upstream project tags a release. Don't edit `Formula/*.rb` by hand — the next
release will overwrite it.

## What's here

- **[deckk](https://github.com/holman/deckk)** — point it at a URL, get a PDF.

```
brew install holman/tap/deckk
```
